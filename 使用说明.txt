========================================
  DSH 便携版 — 使用说明
  DeepSeek Harness 免安装便携版
========================================

运行要求（先看一眼，免得白折腾）

  * 64 位的 Windows 10 1809 (Build 17763) / Windows 11 及以上
    （本包自带 Node.js 22，官方不支持 Win7 / 8 / 8.1 和早期 Win10）
  * 建议解压到短路径，例如  D:\DSH\  或  C:\DSH\
    （包内最长路径 197 字符，放太深可能超过 Windows 的 260 字符上限）
  * 第一次启动会自动做一次环境预检；不满足要求会弹窗直接说原因，
    不会让你对着一串看不懂的报错发呆

解压即用，不需要懂命令行。


----------------------------------------
一、开始使用（3 步）
----------------------------------------

1) 把整个文件夹解压到你想放的位置
   （桌面、D 盘都行；不要直接在压缩包里双击，会报错）

2) 双击   DSH 便携版.exe
   会弹出一个启动器窗口，自动做一遍环境自检。
   （如果 exe 被安全软件拦了，改用同目录的 启动 DSH.vbs，效果一样）

3) 第一次用：点窗口里的「设置密钥」，粘贴你的 DeepSeek API 密钥
   （sk- 开头，在 https://platform.deepseek.com 后台可以创建）
   然后点「启动 DSH」—— 稍等 30~60 秒，会自动打开一个独立窗口显示界面。

   * 没填密钥也能启动（只会提示一下）。进去后在网页界面里补填就行，
     所以你可以先启动看看效果，回头再配密钥。

之后每次使用：双击 DSH 便携版.exe → 点「启动 DSH」就行了。


----------------------------------------
二、启动器按钮说明
----------------------------------------

【第一排】

  ▶ 启动 DSH  …… 启动服务并打开界面（已启动过就直接打开）
  环境自检    …… 重新检查系统、磁盘、运行时、端口、冲突等
  设置密钥    …… 填/改你的 DeepSeek API 密钥
  数据目录    …… 打开本文件夹（聊天记录、配置都在里面）
  停止服务    …… 关掉后台服务（不用时可点，省内存）

【第二排：清理与修复，都只影响本文件夹】

  干净卸载…   …… 勾选要删的项目：桌面快捷方式 / 密钥 / 数据 / 日志 /
                   整个文件夹。不会动系统里的东西（不改 PATH、
                   不动 C:\Users\你\.dsh、不卸载任何已装软件）

  还原初始状态 …… 把 data\.dsh 还原成刚解压时的样子（插件、主题、配置
                   都恢复）。已保存的 API 密钥不受影响

  强制覆盖…   …… 检测到冲突时的「硬重置」。需要连续确认 3 次
                   （最后要手动输入「覆盖」两个字）才会执行

  创建/删除桌面  …… 桌面快捷方式完全可选。首次启动会问一次要不要；
  快捷方式          之后随时可以用这个按钮开关。不会覆盖桌面上
                   已有的同名快捷方式

  默认原则：发现已有数据就保留，绝不静默覆盖。
  只有你明确点了「强制覆盖」并走完三重确认，才会重置本包自己的数据。


----------------------------------------
三、这个包的特点
----------------------------------------

  [√] 自带运行环境：内置 Node.js，不需要你另装任何东西，也不改系统 PATH
  [√] 绿色免安装：所有文件都在这个文件夹里，删掉文件夹 = 完全卸载
  [√] 不与系统上已有的 dsh 冲突：本包使用独立的数据目录（data\.dsh），
      不会动你 C:\Users\你\.dsh 里的任何东西
  [√] 环境自检 + 冲突检测：启动器会列出所有检查项，冲突项用黄色标出，
      默认不覆盖
  [√] 端口自动避让：3080 被占用时会自动换端口
  [√] 密钥只存本地：存在 config\api-key.txt，不上传任何地方
  [√] 已装好外观：海洋主题（open-sea-skin）+ 余额鲸鱼娘挂件 +
      galgame 对话视图

四、常见问题
----------------------------------------

Q: 双击 exe 没反应？
   右键「以管理员身份运行」试一次；或改用同目录的 启动 DSH.vbs /
   start-dsh.cmd。

Q: 提示被 Windows 安全中心 / 杀毒软件拦截？
   Win11 的「Smart App Control」可能拦未签名程序。
   到 设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 放行，
   或改用 启动 DSH.vbs（vbs 入口一般不会被拦）。
   如果仍被拦，对 node\node.exe 也放行一次。

Q: 窗口打开是空白 / 打不开？
   点「停止服务」，然后重新点「启动 DSH」。

Q: 想换回干净外观 / 插件坏了？
   点「还原初始状态」，会用包内模板重建 data\.dsh。

Q: 想把记录搬到别的电脑？
   整个文件夹拷走即可，data 文件夹里就是全部数据。

Q: 界面右下角那个摇来摇去的鲸鱼娘是什么？
   余额挂件，会显示你的 DeepSeek 余额和每轮消耗；
   对话页上方的「GAL视窗」标签可以把对话界面切成 galgame 风格；
   背景的实时海浪是 open-sea-skin 皮肤（左下角有小面板可以调）。

五、目录结构
----------------------------------------

  DSH-Portable\
    ├─ DSH 便携版.exe        双击这个（图形启动器）
    ├─ 使用说明.txt          本文件
    ├─ 启动 DSH.vbs          备用入口（被拦时用）
    ├─ start-dsh.cmd         备用入口（能看到报错信息）
    ├─ launcher\             启动器程序 + 核心逻辑
    ├─ node\                 自带的 Node.js 运行时 + dsh 本体（不要删）
    ├─ assets\               图标等资源
    ├─ seed\.dsh\            初始模板（「还原初始状态」用，不要删）
    ├─ config\api-key.txt    你的密钥（第一次填完后才有）
    ├─ data\.dsh\            聊天记录 / 插件 / 配置（你的数据）
    ├─ tools\                验证脚本
    └─ logs\                 运行日志（出问题时可发给我）


----------------------------------------
六、不放心的话，自己验证一遍「它不碰你的电脑」
----------------------------------------

包里带了验证脚本。它会 先给电脑拍快照 → 反复运行几轮（自检 + 起停服务）
→ 再拍一次 → 逐项对比，确认除了这个文件夹本身，系统里什么都没被创建或修改。

在文件夹里按住 Shift 右键 → 「在此处打开 PowerShell」，然后粘贴执行：

  powershell -ExecutionPolicy Bypass -File .\tools\verify-isolation.ps1 -Rounds 3 -Port 3099

看到「通过：包外环境【零改动】」（并列出 ~/.dsh、PATH、注册表、文档/桌面
四项都没变）就说明是安全的。

运行期间会临时占用 3099 端口；如果本机另有 dsh 在跑，先把它关掉再验，
免得误报。
